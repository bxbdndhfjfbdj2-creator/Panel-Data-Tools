# 衡策可靠性改进实施计划

依据：`audit/项目系统复审报告.md` 与 `audit/改进事项.csv`。用户要求 Luna 执行、主智能体自行审核。

## 目标与边界

本轮交付可信性修复版本，执行下列六项任务，覆盖全部 P0，以及能够在现有产品中明确验证的 P1。保留五步工作流和 Grok 平台契约，不引入账号、数据库、云同步或新的统计推断承诺。

Worker 全量改造、IndexedDB 数据版本管理、完整导入向导、共同因子/CFA、复杂抽样与多重插补属于后续专项；本轮先明确能力边界、阻止静默错误并写入路线图。原审查报告作为历史证据保留，不覆盖成“全部修复”。

## 全局约束

- 执行模型为 `gpt-6-luna`，一次一个任务，禁止执行者继续派生子智能体。
- 主智能体审核规格与代码质量，独立运行关键反例及最终门禁；不直接修改业务代码代替执行者。
- 不削弱测试、不跳过已有测试来制造通过；缺失真实调查夹具改为交付可移植合成夹具，不能声称仍验证了原真实调查数据。
- 原始值、字段和标识符默认保真；任何不支持的格式、方法或规模须明确提示，不能静默换算法或伪造诊断。
- 不删平台脚本/桥接/预置认证；不启用 auth/db；不更改真实项目标题以迎合测试。
- 每任务写执行报告，列修改文件、测试命令、结果与局限；主审核记录通过或退回理由。
- 所有代码修改和审核后补丁均纳入 Git；只在当前隔离提取目录的 `codex/reliability` 工作分支工作，不推送、不部署。

## Task 1：建立可执行的质量门禁

统一 Node 22/24 可运行的业务 TypeScript 测试入口，默认覆盖全部现有业务与平台测试。消除 PWA 标题测试对真实站点文件的隐式依赖；用明确命名的项目相对路径合成 Stata 与 Excel 夹具替代缺失真实数据测试。修复当前 lint 错误/警告；忽略审计历史、构建生成物，不能关闭业务规则。提供 `test:business` 与 `test:platform`，默认执行两组并汇总失败。新增 CI，运行安装、test、typecheck、lint、build。验收：原 36 项业务覆盖意图保留，平台测试可重复通过，门禁不遗漏新 `*.test.ts`。

## Task 2：修复数据导入保真

覆盖 F01/F02/F07/F16。取消默认问卷缺失编码和值标签替换，不自动改写合法数字。CSV/TSV 自动识别分隔符，规范重复/空表头并保持所有列；实体编号保留前导零和大整数。完整候选目录保留稀疏数值列，元数据标签与数值分离。Stata 按 map/数据长度定位，不搜索数据内部结束文本；实现 strL 或明确拒绝含不支持的 strL 文件，优先实现。补 117/118/119、嵌入标记、strL、负数、97/99、TSV、重复列、前导零与长编号回归。拒绝格式必须有明确中文错误。保留原始宽表缓存以供重映射；说明当前 Excel 默认选表规则。

## Task 3：修复数值内核与 AHP

覆盖 F03/F05/F06/F09 的大数组异常。统一 AHP 矩阵语义：左端左9倍重要→左90%，中点50%。改进对称特征分解迭代、收敛与残差诊断，未收敛明确失败；修复未归一化 gamma=1 Varimax，使目标不下降。奇异矩阵共线剔除不得先丢独立变量。去除大样本路径数组展开求极值。独立回归：2/3维 AHP、12/24/60/80维稠密 PSD 特征对残差、正交与重构、旋转目标、独立变量放首/尾及排列、150000行 TOPSIS。不能只提高一个常数而忽略收敛。

## Task 4：修复聚合与筛选契约

覆盖 F04/F08/F12/F13/E01。完整数据 TOPSIS 不因 missing 开关改变；无定义的可用指标 TOPSIS 组合明确拒绝，并让界面不能选择。贴近度0–1；维度展示口径明确。超过48列不伪造单位相关矩阵，应计算声明范围内真实诊断或明确未计算。形成性维度不受反映性信度筛选规则阻断；非阻断提示可见；可靠性/热图/筛选变换口径一致并标明候选集。空维度不参加零权重回退；PCA解释方差汇总顺序无关。实现中位数/10%切尾均值并接入既有 UI；贡献分解与标准化、逐行缺失和时期平均一致，对非加性方法不宣称可加解释。补手算与不变性测试。

## Task 5：统一分析视图、状态和复现

覆盖 F10/F11/F14/F15/F17。统一年份窗口与结果视图的选行规则，主表、方法对照、留一、重抽样、拟合及报告同口径；缺失时间不能变成0年，展示各自最新观测实际年份。将36次探索性重抽样明确称敏感性范围，显示有效次数和停用原因，不冒充完整置信区间。完整方案schema校验与兼容默认值，拒绝非法枚举/非有限数/重复key/悬空引用；赋维/自动构念动作保证纳入与实际计分一致。保存返回结果，失败有提示且不能更新成功时间；步骤切换不重写大型数据。报告包含完整配置、样本口径、实际权重与版本；得分导出避免重名覆盖、Markdown转义，区分当前视图与全量。R/Stata草图醒目标记不等价复现。补方案及选年/均值回归。

## Task 6：依赖、使用文档和交付

处理 xlsx 已公布风险，优先验证官方维护发行或兼容替代，记录来源/版本与锁文件；安全更新传递依赖，不强制破坏 API。补 README、架构说明、方法契约、数据格式与缺失编码说明、运行测试流程、适用限制与后续专项路线图。补输入/滑块语义标签及可点击结果行键盘操作，不重设计整站。增加导入/规模/本地保存与网络资源说明，按实际能力表述。修复明确兼容性问题并报告未解决的风险。构建生成物和运行日志排除版本管理，保留必须平台资源。

## 验收与后续

每任务由主智能体审查差异和关键测试；阻断问题退回 Luna。全部完成后运行默认测试、typecheck、lint、build、依赖审计及桌面/手机开发和生产交互验证。验收结论区分已修复、部分缓解、仍待专项，不将探索性模型视为正式测量或推断。

后续专项顺序：Worker/取消/性能基准 → IndexedDB/版本恢复 → 完整导入向导 → 按用户类型选择固定基期或测量模型 → 复杂抽样与多重插补。每个专项需要单独的方法契约与验收输入。
